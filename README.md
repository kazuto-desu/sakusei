# 特定技能 申請書類作成アプリ

特定技能（1号）の申請に必要な参考様式を、**入力した情報から出入国在留管理庁の公式参考様式どおりの Excel ファイルで作成する**ブラウザアプリです。
作成した Excel はそのまま編集・印刷できます。様式のひな形はアプリに内蔵しています。

- `app/index.html` を Microsoft Edge か Google Chrome で開くだけで使えます。インストールやサーバーは不要です。
- Claude など外部サービスには依存しません。インターネットに接続されていなくても動きます。

## 作成できる書類

選んだ書類を **1つの Excel ファイル（.xlsx）にまとめて**保存します（1書類＝1シート。個人ごとの書類は1人1シート）。

| 区分 | 様式 | ミャンマー語併記版 | 同時申請の連名 |
| --- | --- | --- | --- |
| 雇用 | 参考様式第1-4号 特定技能外国人の報酬に関する説明書 | ― | ○（選択） |
| 雇用 | 参考様式第1-5号 特定技能雇用契約書 | ○ | ― |
| 雇用 | 参考様式第1-6号 雇用条件書（別紙1 賃金の支払、別紙2 無期転換後の雇用条件） | ○ | ― |
| 雇用 | 参考様式第1-16号 雇用の経緯に係る説明書 | ○ | ○（選択） |
| 支援 | 参考様式第1-17号 1号特定技能外国人支援計画書（公式Excel版） | 翻訳様式を添付 | ○（既定） |
| 支援 | 参考様式第1-25号 登録支援機関との支援委託契約に関する説明書 | ― | ○（既定） |
| 支援 | 参考様式第5-10号 支援委託契約書（別紙 支援委託費用内訳） | ― | ○（既定） |

- **同時申請（複数名）**：案件に外国人を複数追加すると、上の「連名」の書類ごとに、1部にまとめるか1人ずつ作るかを選べます。まとめる書類は氏名欄を「別紙のとおり」（1-17 は「別紙の名簿のとおり」）とし、公式の **立証資料の対象となる申請人の名簿（参考様式・補助用紙）** のシートを付けます（1-17 の名簿には署名日欄を付けます）。
- **ミャンマー語**：翻訳言語をミャンマー語にすると、1-5・1-6（別紙含む）・1-16 は公式のミャンマー語併記版で作成し、1-17 には公式のミャンマー語の翻訳様式シートを付けます（翻訳様式は記入欄が日本語版と異なるため自動入力しません）。
- 雇用条件書の別紙2 は、無期転換後の労働条件の変更が「有」のときだけ作成します。
- 旧様式の 1-9「徴収費用の説明書」は、現行の 1-17 の「3-ア-ｄ 住居の概要・居住費」に統合されているため、1-17 に記入します。
- 5-10 の「覚書」は公式参考様式にないため作成しません（必要な場合は Excel 上で追加してください）。

在留資格認定証明書交付申請書（申請人等作成用・所属機関等作成用）と、所属機関関係の書類（1-11・役員一覧・1-23・1-27）は、今後追加する予定です。

## Excelと比べて楽になること

| これまで（Excel） | このアプリ |
| --- | --- |
| 案件ごとに受入機関・支援機関の情報を入力 | **マスタに一度登録**すれば、案件では選ぶだけ |
| 前の案件のファイルをコピーして上書き → 前の人の情報が残る危険 | 案件ごとに独立。毎回まっさらな公式様式から作るので**前の人の情報が混ざらない** |
| 2人目以降も給与・労働条件・支援内容を入力し直し | **同時申請**（連名・個別を選択）、**直近案件からの引き継ぎ**、**案件の複製** |
| 月給換算・時給換算・年間労働時間・手取り額をExcelで確認 | 入力中に自動計算。年間2085.7時間超・週40時間超などを警告 |
| 契約期間（1年後の前日）や所定労働日数・時間を手で計算 | 自動計算して書類に記載 |
| 入力漏れは目で確認 | 必須項目・形式・日付の前後関係・18歳未満・旅券期限切れを自動チェック |
| ミャンマー語の一部が古い文字コード（Zawgyi）で、環境によって文字化け | 国際標準の Unicode に変換して内蔵 |

## 使い方

1. `app` フォルダごと各自のPC（または社内共有フォルダ）に置き、`app/index.html` を Edge か Chrome で開きます。
2. 初回はパスワードを設定します（8文字以上）。
3. **受入機関・登録支援機関・外国人** を登録します（一度登録すれば使い回せます）。
4. **案件 → ＋ 新しい案件** で、外国人・受入機関・登録支援機関を選んで作成します（自社で支援する場合は登録支援機関「なし」）。同時申請の場合は「1. 紐付け」で外国人を追加し、連名にする書類を選びます。
5. タブの順に入力します：1. 紐付け → 2. 日程・翻訳 → 3. 給与・労働条件 → 4. 書類ごとの入力 → 5. 書類の作成（Excel）。
6. 「5. 書類の作成（Excel）」で作る書類を選び、「選択した書類をExcelファイルで保存」を押して保存先を選びます。
7. 保存した Excel を開いて内容を確認し、必要に応じて編集・印刷します。

> 日付は「2026/12/1」「20261201」「R8.12.1」「2026年12月1日」などの形で入力できます。

### ほかの社員への展開

- `app` フォルダをそのままコピーして配布してください（約1MB）。
- 各社員のデータはそれぞれのPCに保存され、互いに見えません。
- 受入機関などのマスタを共有したい場合は、バックアップファイル（暗号化済み）を渡し、「設定 → バックアップから復元」してもらいます（復元すると、受け取った側のデータは置き換わります）。

## セキュリティ（個人情報・法人情報の保護）

| 対策 | 内容 |
| --- | --- |
| **外部通信なし** | ページに Content-Security-Policy（`connect-src 'none'` ほか）を設定し、スクリプトからの通信をブラウザが遮断します。外部のスクリプト・フォント・CDN も読み込みません。Excel の作成もブラウザ内だけで行います。 |
| **保存はそのPCのみ** | データはブラウザ内（IndexedDB）にだけ保存されます。サーバーやクラウドには送られません。 |
| **暗号化** | マスタ・案件はすべて、パスワードから導出した鍵（PBKDF2-SHA256 31万回）で AES-GCM 256bit 暗号化して保存します。パスワード自体は保存しません。 |
| **自動ロック** | 一定時間（既定15分）操作がないとロックし、メモリ上の鍵を破棄します。 |
| **リポジトリに実データを置かない** | 内蔵のひな形（`app/js/template-data.js`）は、出入国在留管理庁が公開している参考様式だけから作成しています。社内Excelは使っていません。`.gitignore` で Excel・PDF をコミットできないようにしています。テストは架空のデータで行います。 |
| **画面表示の安全性** | 入力値はすべてテキストとして扱い、HTMLとして解釈しません。 |

> 注意：パスワードを忘れるとデータは復元できません。ブラウザの「閲覧データの削除」でサイトデータを消すとデータも消えます。
> 定期的に「設定 → バックアップを作成」で暗号化バックアップを取り、社内の決められた場所に保管してください。
> 保存した Excel には個人情報が含まれます。保存先・送付先に注意してください。

## 注意事項

- チェック機能は入力ミスを減らすための補助です。要件の適合性や記載内容の最終確認は、必ず担当者が行ってください。
- 様式は出入国在留管理庁の参考様式（https://www.moj.go.jp/isa/applications/ssw/10_00020.html ）に基づきます。様式が改訂された場合は、ひな形の作り直しが必要です（下記「開発者向け」）。
- 公式のミャンマー語版 1-6 には、日本語版の「Ⅸ４ 待遇の相違の説明窓口」の欄がありません（公式様式のとおり）。

## 開発者向け

```
app/
  index.html              画面（CSPで外部通信を禁止）
  css/app.css             画面のスタイル
  js/fields.js            マスタ・案件の入力項目
  js/inputs.js            書類ごとの入力項目・作成できる書類の一覧・共通コンテキスト
  js/calc.js              労働時間・月給換算・手取りなどの計算
  js/builder.js           入力チェック
  js/vault.js             暗号化保存（IndexedDB + WebCrypto）、バックアップ
  js/app.js / ui.js       画面
  js/xlsx.js              Excel ひな形の読み書き（シートの複製・セルの書き換え・行の高さ調整）
  js/fill.js              各様式への書き込みルール（様式の文言でセルを探し、空欄・□を埋める）
  js/fill-117.js          1-17 支援計画書（公式Excel版）への書き込みルール
  js/export.js            書類の組み立て（個人ごと・連名・名簿・ミャンマー語版）と .xlsx の出力
  js/template-data.js     公式参考様式のひな形（自動生成）
  js/vendor/jszip.min.js  ZIP（.xlsx）処理ライブラリ（MIT、同梱）
tools/
  build_template.py       公式参考様式（Word・Excel）からひな形を作る
  docx2xlsx.py            Word の様式を、文言・段落・表の構成どおりに Excel シートへ写す
  merge_xlsx.py           公式 Excel 版の 1-17 を書式ごとひな形に結合する
  zawgyi.js               ミャンマー語の Zawgyi → Unicode 変換
tests/
  e2e.js                  ブラウザ操作による結合テスト（Excel 出力まで。外部通信が発生したら失敗）
```

ひな形を作り直す場合（公式サイトから様式をダウンロードし、.doc は LibreOffice で .docx に変換しておく）:

```
pip install openpyxl lxml
cd tools && npm install && cd ..
python3 tools/build_template.py 公式様式のフォルダ
```

必要なファイル：`f1-4.docx f1-5.docx f1-6.docx f1-16.docx f1-25.docx f5-10.docx f1-17.xlsx my.docx`（`my.docx` はミャンマー語版）。
名簿のシートは「立証資料の対象となる申請人の名簿（参考様式・補助用紙）」と同じ並び・罫線で `build_template.py` が作ります。

テストの実行（Node.js が必要）:

```
cd tests
npm install
npm test
```
