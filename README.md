# 特定技能 申請書類作成アプリ

社内で使っている申請書類のExcel（「データ（★）」シートで全様式に転記する仕組みのもの）を**ひな形としてそのまま使い**、
入力・管理・チェックをアプリで効率化するツールです。出力されるのは、元の様式のレイアウトのままのExcelファイルです。

- ブラウザ（Microsoft Edge / Google Chrome）で `app/index.html` を開くだけで使えます。インストールやサーバーは不要です。
- Claude など外部サービスには依存しません。インターネットに接続されていなくても動きます。

## 何が効率化されるか

| Excelでの作業 | アプリでは |
| --- | --- |
| 案件ごとに「データ（★）」へ受入機関・支援機関の情報を毎回入力 | **受入機関・登録支援機関・外国人をマスタ登録**。案件では選ぶだけ |
| 「データ（★）」に無く、各様式に直接書き込んでいた欄（旅券番号、出生地、居住地、入国予定日の年月日、役員一覧、決算、雇用保険番号の1桁ずつの欄など） | マスタ・案件の入力から**自動で各セルへ書き込み** |
| 前の案件のファイルをコピーして上書き → 前の人の情報が残るリスク | ひな形登録時に**残っている値を検出して空にできる**。出力前にも残存欄を警告 |
| 同じ受入機関で2人目以降を作るとき、給与・労働条件・様式の入力をやり直し | **直近案件から引き継ぎ**／**案件の複製** |
| 年間労働時間・月給換算・時給換算・手取りをExcelで確認 | 入力中にリアルタイム計算（Excelの数式と同じ計算）。年間2085.7時間超・週40時間超・日本人との報酬比較などを警告 |
| 入力漏れを目で確認 | 必須項目・形式（法人番号13桁、郵便番号など）・日付の前後関係・18歳未満・旅券期限切れを自動チェック |
| チェック欄（□/■）や説明文 | 「様式ごとの入力」で、各シートの黄色い入力欄を一覧で編集（見出しはExcelから自動推定） |

## セキュリティ（個人情報・法人情報の保護）

| 対策 | 内容 |
| --- | --- |
| **外部通信なし** | ページに Content-Security-Policy（`connect-src 'none'` ほか）を設定し、スクリプトからの通信をブラウザが遮断します。外部のスクリプト・フォント・CDNも読み込みません（ライブラリ JSZip は同梱）。 |
| **保存はそのPCのみ** | データはブラウザ内（IndexedDB）にだけ保存されます。サーバーやクラウドには送られません。 |
| **暗号化** | マスタ・案件・ひな形のExcelはすべて、パスワードから導出した鍵（PBKDF2-SHA256 31万回）で AES-GCM 256bit 暗号化して保存します。パスワード自体は保存しません。 |
| **自動ロック** | 一定時間（既定15分）操作がないとロックし、メモリ上の鍵を破棄します。 |
| **出力ファイルの後処理** | 作成者名・最終更新者（PC名）とアドイン参照を除去し、数式のキャッシュ値（前の案件の計算結果）を消して、開いたときに再計算させます。 |
| **リポジトリに実データを置かない** | ひな形のExcelはリポジトリに含めません。`.gitignore` で `.xlsx` などをコミットできないようにしています。テストは生成したダミーのひな形で行います。 |
| **画面表示の安全性** | 入力値はすべてテキストとして表示し、HTMLとして解釈しません。 |

> 注意：パスワードを忘れるとデータは復元できません。また、ブラウザの「閲覧データの削除」でサイトデータを消すとデータも消えます。
> 定期的に「設定 → バックアップを作成」で暗号化バックアップを取り、社内の決められた場所に保管してください。

## 使い方

1. `app` フォルダごと各自のPC（または社内共有フォルダ）に置き、`app/index.html` を Edge か Chrome で開きます。
2. 初回はパスワードを設定します（8文字以上）。
3. **ひな形（Excel）** で社内の申請書類Excelを登録します。前の案件の値が残っている場合は、空にするシートを選べます（翻訳文などの定型文は残せます）。
4. **受入機関・登録支援機関・外国人** を登録します（一度登録すれば使い回せます）。
5. **案件 → ＋ 新しい案件** で、外国人・受入機関・支援機関を選んで作成します。
6. タブの順に入力します：1. 紐付け → 2. 日程・入国 → 3. 給与・労働条件 → 4. 様式ごとの入力 → 5. チェック・Excel出力。
7. 「Excelファイルを出力」で保存先を選んで保存し、Excelで開いて内容を確認・印刷（PDF化）します。

### ほかの社員への展開

- `app` フォルダをそのままコピーして配布してください（約120KB＋ライブラリ）。
- 各社員のデータはそれぞれのPCに保存され、互いに見えません（Aの方式）。
- 社員間で受入機関などのマスタを共有したい場合は、バックアップファイル（暗号化済み）を渡し、「バックアップから復元」してもらいます（復元すると、受け取った側のデータは置き換わります）。
- ブラウザ拡張機能はページの内容を読める場合があるため、業務PCでは許可された拡張機能のみを使ってください。

### 様式が改訂されたとき

新しいExcelを「ひな形」に登録して「既定」にしてください。シート名とセル位置で書き込むため、
入力欄の位置が変わった場合は `app/js/mapping.js` のセル番地を修正します（各項目に `sheet` と `cell` が書いてあります）。
見つからないシートや、数式保護のため書き込めなかった欄は、出力時に表示されます。

## 注意事項

- チェック機能は入力ミスを減らすための補助です。要件の適合性や記載内容の最終確認は、必ず担当者が行ってください。
- 「様式ごとの入力」の項目名は、Excelの近くの見出しから自動で推定しています。セル番地をExcelと照らし合わせて確認してください。

## 開発者向け

```
app/
  index.html          画面（CSPで外部通信を禁止）
  css/app.css
  js/xlsx.js          ひな形の読み込み・黄色セルの抽出・XMLを直接書き換える出力処理
  js/mapping.js       入力項目とExcelセル番地の対応表
  js/builder.js       案件 → セル書き込み内容の組み立て、入力チェック
  js/calc.js          「データ（★）」の計算式の再現
  js/vault.js         暗号化保存（IndexedDB + WebCrypto）、バックアップ
  js/app.js / ui.js   画面
  js/vendor/jszip.min.js（MIT、同梱）
tests/
  make_fixture.py     ダミーのひな形を生成（実データなし）
  e2e.js              ブラウザ操作による結合テスト（外部通信が発生したら失敗）
  verify.py           出力Excelの検証
```

テストの実行（Node.js・Python 3・openpyxl が必要）:

```
cd tests
npm install
npm test
```
