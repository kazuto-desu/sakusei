# 特定技能 申請書類作成アプリ

特定技能（1号）の申請に必要な参考様式を、**入力した情報からそのまま作成し、印刷・PDF保存できる**ブラウザアプリです。
Excelファイルは使いません。様式はアプリに内蔵しています。

- `app/index.html` を Microsoft Edge か Google Chrome で開くだけで使えます。インストールやサーバーは不要です。
- Claude など外部サービスには依存しません。インターネットに接続されていなくても動きます。

## 作成できる書類

| 区分 | 様式 | 翻訳（ミャンマー語）併記 |
| --- | --- | --- |
| 雇用 | 参考様式第1-4号 特定技能外国人の報酬に関する説明書 | ― |
| 雇用 | 参考様式第1-5号 特定技能雇用契約書 | ○ |
| 雇用 | 参考様式第1-6号 雇用条件書 | ○ |
| 雇用 | 参考様式第1-6号 別紙 賃金の支払 | ○ |
| 雇用 | 参考様式第1-9号 徴収費用の説明書 | ― |
| 雇用 | 参考様式第1-16号 雇用の経緯に係る説明書 | ○ |
| 支援 | 参考様式第1-17号 1号特定技能外国人支援計画書 | ○ |
| 支援 | 参考様式第1-25号 登録支援機関との支援委託契約に関する説明書 | ― |
| 支援 | 参考様式第5-10号 支援委託契約書（別紙 支援委託費用内訳・覚書） | ― |

在留資格認定証明書交付申請書（申請人等作成用・所属機関等作成用）と、所属機関関係の書類（1-11・役員一覧・1-23・1-27）は、今後追加する予定です。

## Excelと比べて楽になること

| これまで（Excel） | このアプリ |
| --- | --- |
| 案件ごとに受入機関・支援機関の情報を入力 | **マスタに一度登録**すれば、案件では選ぶだけ |
| 前の案件のファイルをコピーして上書き → 前の人の情報が残る危険 | 案件ごとに独立。**前の人の情報が混ざらない** |
| 2人目以降も給与・労働条件・支援内容を入力し直し | **直近案件からの引き継ぎ**、**案件の複製** |
| 月給換算・時給換算・年間労働時間・手取り額をExcelで確認 | 入力中に自動計算。年間2085.7時間超・週40時間超などを警告 |
| 契約期間（1年後の前日）や所定労働日数・時間を手で計算 | 自動計算して書類に記載 |
| 入力漏れは目で確認 | 必須項目・形式・日付の前後関係・18歳未満・旅券期限切れを自動チェック |
| 支援計画書のミャンマー語の一部が古い文字コード（Zawgyi）で、環境によって文字化け | 国際標準の Unicode に統一して内蔵 |
| 支援委託費用・覚書を毎回入力 | **登録支援機関マスタに費用内訳を登録**し、委託料（月額）を自動計算 |

## 使い方

1. `app` フォルダごと各自のPC（または社内共有フォルダ）に置き、`app/index.html` を Edge か Chrome で開きます。
2. 初回はパスワードを設定します（8文字以上）。
3. **受入機関・登録支援機関・外国人** を登録します（一度登録すれば使い回せます）。翻訳文に使う外国語表記（名称・住所など）もここで入力します。
4. **案件 → ＋ 新しい案件** で、外国人・受入機関・登録支援機関を選んで作成します（自社で支援する場合は登録支援機関「なし」）。
5. タブの順に入力します：1. 紐付け → 2. 日程・翻訳 → 3. 給与・労働条件 → 4. 書類ごとの入力 → 5. 書類の作成・印刷。
6. 「5. 書類の作成・印刷」で作る書類を選び、「選択した書類を表示して印刷・PDF保存」を押します。表示された書類を確認し、「印刷・PDF保存」で印刷するか、送信先に「PDFに保存」を選んでPDFにします。

> ミャンマー語は Windows 標準の「Myanmar Text」フォントで表示・印刷されます。

### ほかの社員への展開

- `app` フォルダをそのままコピーして配布してください（約300KB）。
- 各社員のデータはそれぞれのPCに保存され、互いに見えません。
- 受入機関などのマスタを共有したい場合は、バックアップファイル（暗号化済み）を渡し、「設定 → バックアップから復元」してもらいます（復元すると、受け取った側のデータは置き換わります）。

## セキュリティ（個人情報・法人情報の保護）

| 対策 | 内容 |
| --- | --- |
| **外部通信なし** | ページに Content-Security-Policy（`connect-src 'none'` ほか）を設定し、スクリプトからの通信をブラウザが遮断します。外部のスクリプト・フォント・CDN も読み込みません。 |
| **保存はそのPCのみ** | データはブラウザ内（IndexedDB）にだけ保存されます。サーバーやクラウドには送られません。 |
| **暗号化** | マスタ・案件はすべて、パスワードから導出した鍵（PBKDF2-SHA256 31万回）で AES-GCM 256bit 暗号化して保存します。パスワード自体は保存しません。 |
| **自動ロック** | 一定時間（既定15分）操作がないとロックし、メモリ上の鍵を破棄します。 |
| **リポジトリに実データを置かない** | 様式の固定文言（見出し・条文・注意書き・翻訳文）だけを `app/js/docs/texts.js` に収録しています。社内Excelの入力欄（個人情報）は抜き出しの対象外で、`.gitignore` で Excel・PDF をコミットできないようにしています。テストは架空のデータで行います。 |
| **画面表示の安全性** | 入力値はすべてテキストとして表示し、HTMLとして解釈しません。 |

> 注意：パスワードを忘れるとデータは復元できません。ブラウザの「閲覧データの削除」でサイトデータを消すとデータも消えます。
> 定期的に「設定 → バックアップを作成」で暗号化バックアップを取り、社内の決められた場所に保管してください。
> 印刷・保存したPDFには個人情報が含まれます。保存先・送付先に注意してください。

## 注意事項

- チェック機能は入力ミスを減らすための補助です。要件の適合性や記載内容の最終確認は、必ず担当者が行ってください。
- 様式は出入国在留管理庁の参考様式（社内Excel収録版）に基づきます。様式が改訂された場合は、アプリ側の修正が必要です（下記「開発者向け」）。
- ミャンマー語訳は社内Excelに収録されていた訳文です。利用者が入力する自由記述欄（定例日・昇給の内容など）の翻訳は、各欄の「（ミャンマー語）」に入力してください。

## 開発者向け

```
app/
  index.html              画面（CSPで外部通信を禁止）
  css/app.css             画面・書類（A4印刷）のスタイル
  js/fields.js            マスタ・案件の入力項目
  js/calc.js              労働時間・月給換算・手取りなどの計算
  js/builder.js           入力チェック
  js/vault.js             暗号化保存（IndexedDB + WebCrypto）、バックアップ
  js/app.js / ui.js       画面
  js/docs/common.js       書類作成の共通部品
  js/docs/doc-*.js        各様式（入力欄の定義とレイアウト）
  js/docs/texts.js        様式の固定文言・ミャンマー語訳（自動生成）
tools/
  extract_texts.py        社内Excelから固定文言だけを抜き出す（入力欄は抜き出さない）
  build_texts.js          Zawgyi→Unicode 変換をして texts.js を生成
tests/
  e2e.js                  ブラウザ操作による結合テスト（PDF出力まで。外部通信が発生したら失敗）
```

様式の文言を更新する場合（社内Excelは手元のPCにだけ置き、リポジトリに入れないこと）:

```
python3 tools/extract_texts.py 申請書類.xlsx > /tmp/texts.json
cd tools && npm install && node build_texts.js /tmp/texts.json > ../app/js/docs/texts.js
```

テストの実行（Node.js が必要）:

```
cd tests
npm install
npm test
```
